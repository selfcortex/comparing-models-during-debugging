# Сравнение моделей в дебаге (Python)

Бенчмарк LLM на задаче отладки: модель получает файл [`taskflow.py`](workspace/taskflow.py) — небольшой
движок выполнения графа задач (rate limiter, TTL-кэш, шина событий, DAG, retry, транзакционное
хранилище, сериализация с миграциями и `Engine`), намеренно испорченный **десятками багов** — от
простых до очень неочевидных: логика, граничные случаи, порядок операций, копирование данных,
взаимодействие компонентов, глубина рекурсии, асимптотика.

Правила задачи ([`workspace/TASK.md`](workspace/TASK.md)):

- **Docstring'и — это контракт.** Если код и docstring расходятся, прав код.
- Публичный API менять нельзя, только стандартная библиотека Python 3.
- Исправлять причину, а не симптом; результат проверяет независимый набор проверок, которого у модели нет.

Результат каждой прогону проверяет **скрытый эвалюатор** — [`evaluator/evaluate.py`](evaluator/evaluate.py):
49 взвешенных проверок (суммарный вес 149), включая рандомизированные дифференциальные тесты
(fuzz) против эталонной модели. Итоговый счёт — 0…100.

- **Qwen 3.8 27B + LoRA** крутилась локально со скоростью менее 30 t/s, но справилась
  примерно за 20 минут и потеряла лишь одну проверку (`engine.rate_limit`).
- ChatGPT «сыпался» в одной теме — транзакции/удаления в `Store` (3 проверки).
- DeepSeek v4.1 Flash — самый быстрый (≈6 мин) и полный результат; Qwen4Max — полный

### Первые наблюдения

- Задача «честно» различает модели: от 0 (лимит без LoRA) до 100.
- Сложнее всего оказались: транзакционное хранилище с вложенными commit/rollback,
  атомарность попыток в `Engine` и rate limiting; их-то и не закрыли модели с ошибками.
- Локальная модель с LoRA почти дотянула до полного счёта за ~20 мин при < 30 t/s —
  адаптер дал +97.3 балла против полного провала без него.
- API-модели показали себя в 2–3 раза быстрее по времени, чем локальный запуск.

## Структура репозитория

```
workspace/               исходная задача
  TASK.md                условия задачи
  taskflow.py            исходник с багами (оригинал, не трогаем)

evaluator/               скрытый эвалюатор (не показываем моделям!)
  evaluate.py            49 взвешенных проверок, счёт 0..100, --json
  compare.py             сравнение нескольких результатов (группы по имени файла)
  new_run.sh             создание чистого workspace для новой прогону
  reference_taskflow.py  эталонный (исправленный) модуль

runs/                    прогоны моделей
  lora_1/                Qwen 3.8 27B + LoRA (taskflow.py + свои тесты в tests/)
  no_lora_1/, no_lora_2/ Qwen 3.8 27B без LoRA — файл не изменён (провал)
  chatgpt/               ChatGPT
  qwen4max/              Qwen4Max
  deepseek v4.1 flash/   DeepSeek v4.1 Flash

results/                 результаты эвалюатора (JSON, по одному файлу на прогон)
  lora_1.json            97.3
  chatgpt.json           91.9
  qwen4max.json          100.0
  deepseek_v4.1_flash.json  100.0
```

## Как прогнать новую модель

```bash
# 1. чистая копия задачи для новой прогону
./evaluator/new_run.sh <имя_прогона>        # например: ./evaluator/new_run.sh gemini_1

# 2. дать модели папку runs/<имя_прогона>/ (TASK.md + taskflow.py) и дождаться, пока она закончит

# 3. оценить
python3 evaluator/evaluate.py runs/<имя_прогона>/taskflow.py --json results/<имя_прогона>.json

# 4. сравнить со старыми
python3 evaluator/compare.py results/lora_1.json results/chatgpt.json results/<имя_прогона>.json
```

`compare.py` группирует файлы по части имени до последней `_` (`lora_1.json` → группа `lora`),
показывает среднее/мин/макс/стд по счёту, pass-rate по каждой проверке и по областям.

## Методика

- Каждая проверка эвалюатора изолирована: свои фикстуры, wall-clock таймаут на проверку,
  общий лимит рекурсии 1000 (задача требует итеративных реализаций).
- Fuzz-проверки гоняют случайные программы против наивной эталонной модели,
  чтобы поймать «затыкание» конкретных входных данных.
- Счёт = взвешенная доля пройденных проверок, 0…100.
- Время в таблицах — субъективная оценка длительности прогона модели;
  скорость локального запуска (t/s) указана отдельно, т.к. она влияет на сравнимость.
